# Submission Quickstart

## Run locally

1. Install Node.js 20 or newer.
2. Extract this project folder.
3. Run `npm install` to install the dependencies declared in `package.json`.
4. Run `npm run dev` and open the local URL printed by Vite.
5. Before submission, run `npm run build` and resolve any reported errors.

## Important demo limitations

- Scholarship records are illustrative sample data; confirm every opportunity with its official provider.
- Profile, saved opportunities, application tracker and checklist data are stored in this browser's local storage only.
- There is no backend, account authentication, secure document vault, live scholarship feed or cross-device sync.
- Do not store sensitive identity or financial documents in this demonstration app.
